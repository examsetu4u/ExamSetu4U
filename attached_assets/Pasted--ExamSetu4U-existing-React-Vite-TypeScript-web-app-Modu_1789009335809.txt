मैं ExamSetu4U नाम की existing React + Vite + TypeScript web app पर काम कर रहा हूं।

Modules 1–4 पहले से complete हैं:

- Module 1: Frontend foundation
- Module 2: Exam → Subject → Topic syllabus navigation
- Module 3: Study Material system
- Module 4: PYQ system

अब केवल MODULE 5 – FULL MCQ QUIZ ENGINE implement करना है।

IMPORTANT:

- Existing project को rebuild मत करना।
- Existing UI/design को unnecessarily change मत करना।
- Modules 1–4 की functionality बिल्कुल break नहीं होनी चाहिए।
- Existing routes/components/data/progress system को preserve करो।
- पहले existing code inspect करो और उसी architecture के ऊपर Module 5 बनाओ।
- अभी backend/database/auth मत बनाओ।
- अभी local sample data + localStorage इस्तेमाल करो।
- Code future में thousands of questions और backend/API/database पर migrate करने योग्य होना चाहिए।
- Module 6 शुरू मत करना।
